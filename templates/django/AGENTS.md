# AGENTS.md

이 저장소에서 작업하는 **모든 코딩 에이전트**(Claude Code, Codex, Cursor, OpenCode 등)의
공통 정본이다. 플랫폼별 파일(`CLAUDE.md` 등)은 보충 자료이며, 이 문서의 권한·경계 규칙을
완화할 수 없다.

**규칙 본문은 정본 한 곳에만 둔다.** 이 문서는 정본의 위치를 가리키고 내용을 복사하지
않는다. 요약이 원본과 어긋나는 드리프트를 막기 위해서다.

---

## 시작 전

1. 이 문서와 아래 "규칙 문서" 중 관련 항목을 읽는다.
2. 작업 범위, 영향 파일, 민감 영역 여부, 사람 승인이 필요한지를 먼저 말한다.
   불확실하면 추측해 구현하지 말고 질문한다.
3. 구조는 조회하고 의미는 읽는다. 어디에 무엇이 있고 무엇이 무엇을 부르는지는
   codegraph 로 조회한다 (파일을 훑지 않는다). 상태값의 뜻·시그널 부수효과처럼
   코드에서 재도출할 수 없는 것은 `DOMAIN.md` 를 본다.

## 작업 원칙

플랫폼과 무관한 행동 지침이다. 속도보다 신중함을 우선한다.

**1. 코딩 전에 생각한다**
- 가정을 명시적으로 밝히고, 불확실하면 질문한다.
- 여러 해석이 가능하면 조용히 하나를 고르지 말고 선택지를 제시한다.
- 더 단순한 방법이 있으면 말한다. 필요하면 반론한다.

**2. 단순함 우선**
- 요청받은 것만 구현한다. 추측성 기능, 단일 사용 코드의 추상화, 불가능한 시나리오의
  에러 처리는 넣지 않는다.
- 200줄로 쓴 것이 50줄로 되면 다시 쓴다.

**3. 외과적 변경**
- 요청과 직접 관련된 코드만 고친다. 인접 코드 "개선", 포맷 정리, 리팩터링은 하지 않는다.
- 본인 스타일과 달라도 기존 스타일을 따른다.
- 내 변경으로 생긴 미사용 import·변수·함수만 제거한다. 기존 데드코드는 언급만 한다.
- 기준: 변경된 모든 줄이 요청으로 직접 추적되어야 한다.

**4. 검증 가능한 목표로 전환**
- "검증 추가" → "잘못된 입력 테스트를 쓰고 통과시킨다"
- "버그 수정" → "재현 테스트를 쓰고 통과시킨다"
- "리팩터링" → "전후 테스트 통과를 확인한다"

**5. 통과를 주장하기 전에 증거를 남긴다**
- 검사가 0건을 반환한 것은 안전 신호가 아니라 검사기가 깨졌다는 신호일 수 있다.
- SKIP 을 PASS 로 보고하지 않는다. 실행하지 못한 검증은 실행하지 못했다고 말한다.
- 완료를 선언하기 전에 `TODO` 자리표시자, skip 처리한 테스트, 미구현 분기가 남아
  있는지 변경 파일을 확인한다.

## 권한과 경계

- 기본 브랜치에 직접 push 하지 않는다. 변경은 브랜치 → PR 을 거친다.
- 에이전트는 스스로 머지하지 않는다. 권한 있는 사람이 해당 PR 의 머지를 명시적으로
  요청한 경우에만 수행하며, 그 승인은 다음 PR 로 이어지지 않는다.
- 운영 배포, 시크릿·환경변수 값 열람, 운영 DB 직접 조작은 하지 않는다.
- 되돌리기 어려운 작업(이력 재작성, 대량 삭제, 스키마 파괴 변경)은 실행 전에 사람에게
  확인받는다.
- 승인은 전이되지 않는다. 한 작업을 승인받았다고 인접한 다른 작업까지 승인된 것이 아니다.

## 규칙 문서

주제별 상세는 아래 파일이 정본이다. 필요한 것만 읽는다.

| 주제 | 파일 |
|---|---|
| 지식 계층 (구조 vs 의미) | `.claude/rules/knowledge.md` |
| 아키텍처·레이어 경계 | `.claude/rules/architecture.md` |
| 테스트 작성 | `.claude/rules/testing.md` |
| DOMAIN.md 운영 | `.claude/rules/domain.md` |
| 에이전트 팀 파이프라인 | `.claude/rules/agents.md` |
| 훅·인사이트 | `.claude/rules/hooks.md` |
| 아키텍처 의사결정 기록 | `.claude/decisions/` |

`.claude/` 아래 있지만 특정 도구 전용이 아니다. 어떤 에이전트든 이 경로를 읽으면 된다.

## 문서 규율

- 규칙 본문은 정본 한 곳에만 쓴다. 다른 문서는 **참조**만 한다. 같은 규칙을 두 곳에
  적으면 한쪽을 고칠 때 다른 쪽이 조용히 낡는다.
- 마커(`harness:auto`) 사이는 생성 구간이다. 직접 편집하지 말 것 — 덮어쓰인다.
  내용을 바꾸려면 정본(`.claude/gates.json`, `.claude/settings.json`)을 고친다.
- 게이트를 추가·수정하면 그 사실이 자동 구간에 반영되는지 확인한다.
  `python3 .claude/scripts/render-agents.py --repo . --check`
